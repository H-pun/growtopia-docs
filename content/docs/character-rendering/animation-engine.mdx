# Animation Engine & Motion States

Rather than storing hundreds of pre-rendered sprite frames for every combination of clothing, Growtopia uses **procedural skeletal transforms** combined with small frame sequences. Body parts and clothing items translate and rotate dynamically in real time.

---

## 1. Skeletal Bone Hierarchy

The character rig is organized in a hierarchical tree where child parts inherit transforms from their parents:

```text
Root (World Position)
 └── Pelvis (Base Y + Hover/Bobbing Offset)
      ├── Legs & Feet (foot1, foot2 stride offsets)
      └── Torso (Shirt & Chest accessories)
           ├── Rear Arm & Hand Item (arm2Angle)
           ├── Front Arm & Hand Item (arm1Angle)
           └── Head
                ├── Face Expression & Eye Blink
                ├── Front & Back Hair
                └── Hat & Accessories
```

When the player moves, jumps, or idles, mathematical oscillation functions modify bone translation offsets (`dx`, `dy`) and rotation angles.

---

## 2. Motion Cycles & Mathematical Formulas

### Idle Cycle (Breathing & Bobbing)
When standing still (`speed == 0`), the avatar breathes with a subtle vertical sinusoidal bobbing:

```text
Y_idle(t) = sin(t * 3.5) * 1.0  (pixels)
```

- **Torso & Head:** Displaced vertically by `Y_idle(t)`.
- **Arms:** Relaxed at rest angle (0 degrees).
- **Eye Blinking:** A periodic timer triggers a 3-frame blink sequence (`Open` -> `Half` -> `Closed` -> `Open`) every 2.5 to 5.0 seconds.

### Walk Cycle (Running Stride)
During lateral movement (`speed.x != 0`):

1. **Feet Stride (Opposing Sine Waves):**
   ```text
   foot1_dy = sin(t * walk_speed) * 3.0
   foot2_dy = -sin(t * walk_speed) * 3.0
   ```
2. **Torso Vertical Bounce:**
   The body bounces slightly with each footstep using absolute sine oscillation:
   ```text
   body_dy = abs(sin(t * walk_speed)) * 1.5
   ```
3. **Arm Counter-Swing:**
   The front and back arms swing in opposite directions to counterbalance leg motion:
   ```text
   arm1_angle = sin(t * walk_speed) * 25.0  (degrees)
   arm2_angle = -sin(t * walk_speed) * 25.0 (degrees)
   ```

### Jump & Fall Cycle
When in the air (`onGround == false`):

| State | Condition | Bone Transformations |
|---|---|---|
| **Rising (Jump)** | `speed.y < -0.1` | Arms angle upward (280 degrees / Superman pose). Feet pull upward (`dy = -2.0`). Hair trails slightly downward. |
| **Falling** | `speed.y > 0.1` | Arms spread outward (45 degrees). Legs extend downward. Hair flutters upward. |

### Punch Cycle
When triggering a punch or tool action:
1. **Front Arm Extension:** `arm1` rotates toward the cursor or straight ahead (0 degrees).
2. **Sprite Substitution:** The standard arm (`player_arm.rttex`) is replaced by the punch arm (`player_puncharm.rttex` or `custom_punch` texture).
3. **Recoil Pulse (`UseRecoilAnim`):** The torso and head shift backward by 1–2 pixels for 60ms, then return to baseline.

## 3. Minimal Web Animation Loop (JavaScript / Canvas)

Below is an authentic procedural animation loop implementation suitable for a web-based set planner:

```javascript
export class GrowtopianRig {
  constructor() {
    this.time = 0;
    this.facingLeft = false;
    this.action = 'IDLE'; // IDLE, WALK, JUMP, FALL, PUNCH
    this.blinkFrame = 0;  // 0=Open, 1=Half, 2=Closed
    this.nextBlink = 3000;
  }

  update(deltaTimeMs) {
    this.time += deltaTimeMs / 1000.0;

    // 1. Eye Blink Logic
    this.nextBlink -= deltaTimeMs;
    if (this.nextBlink <= 0) {
      if (this.nextBlink > -60) this.blinkFrame = 1;
      else if (this.nextBlink > -140) this.blinkFrame = 2;
      else if (this.nextBlink > -200) this.blinkFrame = 1;
      else {
        this.blinkFrame = 0;
        this.nextBlink = 2500 + Math.random() * 3000;
      }
    }

    // 2. Bone Transforms based on action
    let bodyDy = 0;
    let foot1Dy = 0;
    let foot2Dy = 0;
    let arm1Angle = 0;
    let arm2Angle = 0;

    if (this.action === 'IDLE') {
      bodyDy = Math.sin(this.time * 3.5) * 1.0;
    } else if (this.action === 'WALK') {
      const walkFreq = 10.0;
      bodyDy = Math.abs(Math.sin(this.time * walkFreq)) * 1.5;
      foot1Dy = Math.sin(this.time * walkFreq) * 3.0;
      foot2Dy = -Math.sin(this.time * walkFreq) * 3.0;
      arm1Angle = Math.sin(this.time * walkFreq) * 25.0;
      arm2Angle = -Math.sin(this.time * walkFreq) * 25.0;
    } else if (this.action === 'JUMP') {
      bodyDy = -2.0;
      arm1Angle = -45.0;
      arm2Angle = 45.0;
    }

    return { bodyDy, foot1Dy, foot2Dy, arm1Angle, arm2Angle, blinkFrame: this.blinkFrame };
  }
}
```
