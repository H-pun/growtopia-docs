# items.dat

`items.dat` is the core client-side binary database in Growtopia. It defines every item's attributes, display names, texture coordinates, physics behavior, collision, rendering shaders, seed/tree properties, and descriptive lore.

The database is downloaded dynamically by the client during handshake (`action|refresh_item_data`) and cached locally.

---

## 1. Header Structure

The file begins with a 6-byte header:

| Field | Type | Size | Description |
|---|---|---|---|
| `version` | `uint16` (Little-Endian) | 2 bytes | Schema version (e.g., `27` in modern client versions). |
| `item_count` | `uint32` (Little-Endian) | 4 bytes | Total number of item definitions contained in the database (e.g., `16434`). |

---

## 2. Types Description

All multi-byte numeric values in `items.dat` are encoded in **Little-Endian** byte order.

| Type | Size | Description |
|---|---|---|
| `uint8` / `int8` | 1 byte | Unsigned / signed 8-bit integer (`0..255`). |
| `uint16` / `int16` | 2 bytes | Unsigned / signed 16-bit integer Little-Endian (`0..65535`). |
| `uint32` / `int32` | 4 bytes | Unsigned / signed 32-bit integer Little-Endian (`0..4294967295`). |
| `string` | 2 + N bytes | Pascal-style string: `uint16` length prefix followed by N bytes of character data. |

For details on primitive types, see [Types Definitions](/docs/items-dat/types-definitions).
</Callout>

## 3. Items Fields Specification (v0 – v27)

Following the 6-byte header, item records appear sequentially from `item_id = 0` to `item_count - 1`.

| # | Field | Type | Version | Description |
|---|---|---|---|---|
| 1 | `item_id` | `uint32` | v0 | Unique numerical item ID (sequential starting from 0). |
| 2 | `properties` | `uint16` | v0 | Item bitflags (interactable, mod-only, consumables, etc.). See [Item Properties](/docs/items-dat/item-properties). |
| 3 | `type` | `uint8` | v0 | Item category enum (e.g., 17=Foreground, 18=Seed, 20=Clothing). See [Item Types](/docs/items-dat/item-types). |
| 4 | `material` | `uint8` | v0 | Material audio & impact particle type (0=Wood, 1=Glass, 2=Rock, 3=Metal). |
| 5 | `name` | `string` | v0 | Item display name. In **v3+**, encoded with an [XOR cipher](/docs/items-dat/cypher) using key `PBG892FXX982ABC*`. |
| 6 | `texture_file` | `string` | v0 | Primary spritesheet path (e.g., `tiles_page1.rttex`). |
| 7 | `texture_hash` | `uint32` | v0 | Checksum/hash of the primary texture. |
| 8 | `visual_type` | `uint8` | v0 | Visual shader effect (0=Normal, 1=Tinted, 25=Rainbow/Shifty, etc.). |
| 9 | `cook_time` | `uint32` | v0 | Cooking duration in seconds (`0xFFFFFFFF` if not cookable). |
| 10 | `tex_x` | `uint8` | v0 | X coordinate in texture sheet (in units of 32 pixels). |
| 11 | `tex_y` | `uint8` | v0 | Y coordinate in texture sheet (in units of 32 pixels). |
| 12 | `storage_type` | `uint8` | v0 | Sprite layout / spread render mode (e.g., 1=spread like dirt). |
| 13 | `layer` | `uint8` | v0 | Rendering layer (0=Foreground, 1=Background). |
| 14 | `collision_type` | `uint8` | v0 | Physical collision behavior (0=None, 1=Solid, 2=One-way platform, 3=Door/Gate). |
| 15 | `hardness` | `uint8` | v0 | Block durability against punch damage. |
| 16 | `regen_time` | `uint32` | v0 | Time in seconds before punch damage resets. |
| 17 | `clothing_type` | `uint8` | v0 | Clothing body slot (0=None, 1=Hat, 2=Shirt, 3=Pants, 4=Shoes, 5=Face, 6=Hand, 7=Back, 8=Hair, 9=Chest). |
| 18 | `rarity` | `uint16` | v0 | Item rarity tier (1..999+). |
| 19 | `max_hold` | `uint8` | v0 | Maximum inventory stack size (default: 200). |
| 20 | `alt_file` | `string` | v0 | Secondary/worn spritesheet path (e.g., character overlay sprite). |
| 21 | `alt_hash` | `uint32` | v0 | Checksum/hash of `alt_file`. |
| 22 | `anim_ms` | `uint32` | v0 | Frame animation duration in milliseconds. |
| 23 | `pet_name` | `string` | v4 | Pet battle system: Pet display name. |
| 24 | `pet_prefix` | `string` | v4 | Pet battle system: Pet title prefix. |
| 25 | `pet_suffix` | `string` | v4 | Pet battle system: Pet title suffix. |
| 26 | `pet_ability` | `string` | v5 | Pet battle system: Special ability string. |
| 27 | `seed_base` | `uint8` | v0 | Column index of base seed sprite in `game/seed.rttex`. See [Seed Rendering](/docs/items-dat/seed-rendering). |
| 28 | `seed_over` | `uint8` | v0 | Column index of overlay seed sprite in `game/seed.rttex`. |
| 29 | `tree_base` | `uint8` | v0 | Column index of tree trunk sprite in `game/tree.rttex`. |
| 30 | `tree_over` | `uint8` | v0 | Column index of tree leaves sprite in `game/tree.rttex`. |
| 31 | `bg_col` | `uint32` | v0 | Little-Endian color tint (`[A, R, G, B]`) for base seed & tree trunk. |
| 32 | `fg_col` | `uint32` | v0 | Little-Endian color tint (`[A, R, G, B]`) for overlay seed & tree leaves. |
| 33 | `bloom_time` | `uint32` | v0 | Growth time in seconds before a tree can be harvested. |
| 34 | `val_c4` | `uint32` | v0 | Special tree / crop status bitflag. |
| 35 | `val_2ac` | `uint32` | v7 | Frame sequence count for custom animated tiles. |

| 54 | `light_radius` | `uint32` | v17 | Light emission radius and intensity in dark worlds. |

| 64 | `val_6f8` | `uint8` | v26 | Account-bound / untradable security flag. |

## 5. Complete Python Reference Parser

This parser has been reverse-engineered from the native macOS Growtopia binary and verified to parse all 16,434 items in `items.dat` v27 with zero byte deviation:

```python
import struct
from dataclasses import dataclass
from typing import List

SECRET = "PBG892FXX982ABC*"

def decrypt_name(data: bytes, item_id: int) -> str:
    klen = len(SECRET)
    return bytes([b ^ ord(SECRET[(i + item_id) % klen]) for i, b in enumerate(data)]).decode("latin1", errors="replace")

@dataclass
class ItemInfo:
    id: int
    name: str
    description: str
    seed_base: int
    seed_over: int
    bg_col: int
    fg_col: int
    bloom_time: int
    seed1: int
    seed2: int

class ItemsDat:
    def __init__(self, filepath: str):
        with open(filepath, "rb") as f:
            self.buf = f.read()
        self.pos = 0
        self.version, self.item_count = struct.unpack_from("<HI", self.buf, 0)
        self.pos = 6
        self.items: List[ItemInfo] = []
        self._parse()

    def _r_str(self, is_xor=False, item_id=0) -> str:
        l = struct.unpack_from("<H", self.buf, self.pos)[0]
        self.pos += 2
        raw = self.buf[self.pos:self.pos+l]
        self.pos += l
        return decrypt_name(raw, item_id) if is_xor else raw.decode("latin1", errors="replace")

    def _r_bytes(self, n: int) -> bytes:
        b = self.buf[self.pos:self.pos+n]
        self.pos += n
        return b

    def _r_u8(self) -> int:
        v = self.buf[self.pos]; self.pos += 1
        return v

    def _r_u16(self) -> int:
        v = struct.unpack_from("<H", self.buf, self.pos)[0]; self.pos += 2
        return v

    def _r_u32(self) -> int:
        v = struct.unpack_from("<I", self.buf, self.pos)[0]; self.pos += 4
        return v

    def _parse(self):
        for i in range(self.item_count):
            item_id = self._r_u32()
            props = self._r_u16()
            itype = self._r_u8()
            mat = self._r_u8()
            name = self._r_str(is_xor=(self.version >= 3), item_id=item_id)
            tex_file = self._r_str()
            tex_hash = self._r_u32()
            vtype = self._r_u8()
            cook_time = self._r_u32()
            tx = self._r_u8(); ty = self._r_u8()
            stype = self._r_u8(); layer = self._r_u8(); ctype = self._r_u8(); hard = self._r_u8()
            rtime = self._r_u32()
            cltype = self._r_u8(); rarity = self._r_u16(); max_hold = self._r_u8()
            alt_file = self._r_str()
            alt_hash = self._r_u32(); anim_ms = self._r_u32()

            if self.version >= 4:
                self._r_str(); self._r_str(); self._r_str()
                if self.version >= 5: self._r_str()

            s_base = self._r_u8(); s_over = self._r_u8()
            t_base = self._r_u8(); t_over = self._r_u8()
            bg_col = self._r_u32(); fg_col = self._r_u32()
            bloom_time = self._r_u32()
            val_c4 = self._r_u32()

            if self.version >= 7:
                val_2ac = self._r_u32(); anim_frames = self._r_str()
            if self.version >= 8:
                tex_extra = self._r_str(); tex_over = self._r_str()
                dlayer1 = self._r_u32(); dlayer2 = self._r_u32()
            if self.version >= 9:
                props2 = self._r_u32(); bot_params = [self._r_u32() for _ in range(15)]
            if self.version >= 10:
                tile_range = self._r_u32(); pile_range = self._r_u32()
            if self.version >= 11:
                custom_punch = self._r_str()
            if self.version >= 12:
                val_360 = self._r_u32(); body_scales = self._r_bytes(9)
            if self.version >= 13:
                clock_div = self._r_u32()
            if self.version >= 14:
                parent_id = self._r_u32()
            if self.version >= 15:
                sit_type = self._r_u8(); sit_transform = self._r_bytes(24)
                alt_sit_path = self._r_str()
            if self.version >= 16:
                alt_hair_path = self._r_str()
            if self.version >= 17:
                light_radius = self._r_u32()
            if self.version >= 18:
                shader_effect = self._r_u32()
            if self.version >= 19:
                collision_bounds = self._r_bytes(9)
            if self.version >= 21:
                aura_slots = self._r_bytes(2)

            desc = self._r_str() if self.version >= 22 else ""
            seed1 = self._r_u16() if self.version >= 23 else 0
            seed2 = self._r_u16() if self.version >= 23 else 0
            val_6f4 = self._r_u8() if self.version >= 24 else 0
            hit_fx = self._r_str() if self.version >= 25 else ""
            val_6f0 = self._r_u32() if self.version >= 25 else 0
            val_6f8 = self._r_u8() if self.version >= 26 else 0
            v27_data = self._r_str() if self.version >= 27 else ""

            self.items.append(ItemInfo(
                id=item_id, name=name, description=desc,
                seed_base=s_base, seed_over=s_over,
                bg_col=bg_col, fg_col=fg_col, bloom_time=bloom_time,
                seed1=seed1, seed2=seed2
            ))
```
